# Case-Study Synthesis

This directory stores HackMD-compatible synthesis drafts built from one or more case-study runs. These files are derived artifacts: raw prompts, responses, retrieval bundles, and eval records stay in `case_studies/runs/<run_id>/`.

## Conventions

- Use one file per synthesis pass.
- Name files as `<date>_<slug>.md`.
- Link to run summaries and mode analyses instead of copying full traces.
- Keep human interpretation in the `Cross-Run Notes` section until a later synthesis pass has stronger evidence.
