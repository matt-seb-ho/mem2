Object shifting based on local context: For each pixel in an object, shift it right (x+1, y) if there are other non-black pixels down and to the right (x+1:, y+1:). Otherwise, keep the pixel in place. This selectively moves parts of an object while preserving the overall shape. (Reference: Q025d127b)
</description>
<example>
```python
for obj in objects:
    transformed = np.zeros_like(obj)
    for x in range(obj.shape[0]):
        for y in range(obj.shape[1]):
            if obj[x, y] != Color.BLACK:
                down_right = obj[x+1:, y+1:]
                if np.any(down_right != Color.BLACK):
                    transformed[x+1, y] = obj[x, y]
                else:
                    transformed[x, y] = obj[x, y]
    blit_object(output_grid, transformed, background=Color.BLACK)
```
Key: The condition checks if there are any colored pixels in the subgrid below and to the right of the current pixel. If yes, shift right; else, stay.
</example>

<description>
Sliding to overlap and repetition: Given a central object and other objects, slide the central object so it completely overlaps each other object (i.e., translate it so that the other object's non-black pixels are a subset of the translated central object's non-black pixels). Choose the displacement vector that maximizes the distance (e.g., largest magnitude). Then recolor the central object to the other object's color. Then repeatedly translate the central object by that displacement vector, blitting each copy, until it falls off the canvas. (Reference: Q045e512c)
</description>
<example>
```python
# For each other_object:
max_disp = (0,0)
for dx in range(-10,10):
  for dy in range(-10,10):
    translated = translate(central_object, dx, dy, background=Color.BLACK)
    if np.all(translated[translated != Color.BLACK] & other_object[other_object != Color.BLACK] == other_object[other_object != Color.BLACK]):
      if dx**2+dy**2 > max_disp[0]**2+max_disp[1]**2:
        max_disp = (dx,dy)
# change color of central_object to color of other_object
# Then repeat:
for i in range(1, max_steps):
  blit_object(output_grid, translate(central_object, max_disp[0]*i, max_disp[1]*i, background=Color.BLACK), background=Color.BLACK)
```
Key: Find displacement vector that makes central object completely cover the other object (other_mask subset of translated_mask) and choose the one with maximum magnitude. Then recolor and repeat.
</example>
