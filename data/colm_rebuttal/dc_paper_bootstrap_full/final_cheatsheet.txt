<description>
**Occlusion filling using translational symmetry**  
When a translationally symmetric pattern is partly occluded by a black rectangle, the missing part can be reconstructed by using the symmetry. Steps: (1) Identify the occluding black rectangle (mask). (2) Detect the translational symmetry of the non‑black part (`background=None` or ignore black). (3) For each occluded pixel, iterate over its symmetric orbits and copy the first non‑occluded color found. (4) Extract the filled region (crop the masked area). The output is the filled‑in sprite (same size as the occluder). (Q: f9012d9b)
</description>
<example>
```python
def fill_occlusion(input_grid):
    occlusion_color = Color.BLACK
    mask = (input_grid == occlusion_color)
    symmetries = detect_translational_symmetry(input_grid, ignore_colors=[occlusion_color], background=None)
    output = input_grid.copy()
    for ox, oy in np.argwhere(mask):
        for sx, sy in orbit(output, ox, oy, symmetries):
            if output[sx, sy] != occlusion_color:
                output[ox, oy] = output[sx, sy]
                break
    filled = np.full_like(output, occlusion_color)
    filled[mask] = output[mask]
    return crop(filled, background=occlusion_color)
```

**Cup filling and shooting lines from opening (generalized)**  
Given a single nearly‑enclosed cup shape (outline) with one opening on its boundary, fill its interior with a given color and extend lines outward from the opening pixels. The opening is a contiguous set of background pixels on the boundary of the cup’s bounding box. Implementation steps: (1) isolate the cup object (connected component), (2) compute the interior mask (everything inside the bounding box that is not part of the cup), (3) compute the hole mask (interior pixels that lie on the bounding box edge), (4) fill interior with chosen color, (5) for each hole pixel, draw a line outward in the direction away from the interior (determined by checking which cardinal direction moves into black outside the bounding box). Variations exist: some puzzles also require shooting diagonals from the two extremal opening pixels; adjust as needed. (Q: aba27056, d4f3cd78)
</description>
<example>
```python
def fill_and_shoot(input_grid, fill_color=Color.TEAL, line_color=Color.TEAL):
    obj = next(iter(find_connected_components(input_grid, connectivity=4, background=Color.BLACK)))
    output = input_grid.copy()
    x, y, w, h = bounding_box(obj)
    interior = np.zeros_like(input_grid, dtype=bool)
    interior[x:x+w, y:y+h] = True
    interior = interior & (obj == Color.BLACK)
    hole = interior.copy()
    hole[x+1:x+w-1, y+1:y+h-1] = False
    output[interior] = fill_color
    # outward direction: test cardinal directions; pick the one that points away from interior
    for dx, dy in [(0,1),(0,-1),(1,0),(-1,0)]:
        cx, cy = x+w//2, y+h//2
        if interior[cx - dx, cy - dy]:
            direction = (dx, dy)
            break
    for px, py in np.argwhere(hole):
        draw_line(output, px, py, direction=direction, color=line_color)
    return output
```

**Mapping object counts to output grid patterns**  
When the output is a small fixed grid and the input contains discrete objects (e.g., 2x2 squares), the output often encodes the number of objects in a specific sparse arrangement. Steps: (1) Identify and count objects using standard detection (connected components, monochromatic checks). (2) Determine the output grid size (often given or constant). (3) Compute a list of positions in the output grid according to a deterministic pattern (e.g., row‑major skipping every other column). (4) Place a marker (e.g., blue pixel) at the first N positions. The pattern may involve alternating offsets per row to create a checkerboard‑like sparseness. (Q: ff28f65a)
</description>

# General approach:
output_size = (3,3)  # often fixed
pattern_offsets = [(r, c) for r in range(output_size[0]) for c in range(output_size[1]) if (r+c)%2 == 0]  # example pattern
count = len(detect_objects(...))
out = np.zeros(output_size, dtype=int)
for i in range(min(count, len(pattern_offsets))):
    out[pattern_offsets[i]] = Color.BLUE
